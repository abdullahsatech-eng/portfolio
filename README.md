## Featured Projects

### 📚 Automated Library Management System

A documented reconstruction of an academic Database Management Systems project developed using **Oracle SQL and PL/SQL**.

The documented system covers:

- Relational database design
- 8 related tables
- Third Normal Form (3NF)
- Primary and foreign-key constraints
- SQL queries and reporting
- PL/SQL trigger for overdue fine generation
- Stored procedure for book issuing
- Database views
- Indexing
- Validation and testing

**Repository:**  
[automated-library-management-system →](https://github.com/abdullahsatech-eng/automated-library-management-system)

> Note: The original source files are no longer available. The repository is a reconstruction based only on the surviving academic documentation and is not presented as the original source code.

**Technologies:** C++ · UML · GRASP · Design Patterns

### 🎓 University Course Registration System

- UML models

**Technologies:** Requirements Engineering · UML · System Analysis
