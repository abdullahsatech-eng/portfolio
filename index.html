A relational database system for library operations — book records, member management, issuing/returns, reservations, and fines. Normalized to 3NF across 8 linked tables, with an automatic fine-calculation trigger and a stored procedure that validates availability before issuing a book.

Social Media Feed Management System

A console simulation of how platforms like Facebook and Instagram manage feeds internally — five data structures working together in one system: a queue for upload processing, a singly linked list for the main feed, a doubly linked list for next/previous navigation, a stack for undoing likes, and array sorting for a trending-posts ranking.

C++ Queue & Stack Linked Lists Sorting
